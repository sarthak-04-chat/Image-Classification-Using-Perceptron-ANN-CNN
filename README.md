# 🧠 Image Classification Using Perceptron, ANN & CNN

A Deep Learning project that implements and compares **Perceptron**, **Artificial Neural Network (ANN)**, and **Convolutional Neural Network (CNN)** models for image classification using TensorFlow and Keras.

---

## 📌 Project Overview

This project demonstrates the implementation of three neural network architectures for image classification:

- 🔹 Perceptron (Single Layer Neural Network)
- 🔹 Artificial Neural Network (ANN)
- 🔹 Convolutional Neural Network (CNN)

The main objective is to compare the performance of these models and understand how deep learning architectures improve image classification accuracy.

---

## 🎯 Objectives

- Perform image preprocessing
- Build Perceptron, ANN, and CNN models
- Train and evaluate each model
- Compare model performance
- Visualize training accuracy and loss
- Predict image classes using trained models

## 🧠 Models Implemented

### 🔹 Perceptron
A single-layer neural network used as the baseline model for image classification.

### 🔹 Artificial Neural Network (ANN)
A fully connected neural network capable of learning complex patterns from image data.

### 🔹 Convolutional Neural Network (CNN)
A deep learning model specifically designed for image processing that automatically extracts important features using convolution and pooling layers.

### Clone the repository

```bash

```

### Navigate to the project directory

```bash
cd Image-Classification-Using-Perceptron-ANN-CNN
```

```bash

```

### Launch Jupyter Notebook

